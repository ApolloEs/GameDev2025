# Lost in Time – 3D Zombie Survival Game

🧟 A 3D first-person zombie survival game made in Unity.  
Developed as a **team project**, focused on AI enemy behaviors, pathfinding, and wave-based combat.

## 🧠 My Contributions

- 🧠 Developed **enemy AI** using Unity NavMesh with patrol, chase, and attack states
- 🔄 Implemented **state transitions** based on player proximity and hit detection
- 💥 Added **blood particle effects** when enemies are hit
- 🧱 Built the **final map layout** and designed level flow
- 🎮 Created the **main menu system** and handled scene management
- 🤝 Assisted teammates in scripting and UI polishing

---

## ⚙️ Features (Team Project)

- First-person zombie survival gameplay
- Enemy waves that increase in difficulty
- Gunplay with shooting and damage feedback
- Pathfinding and enemy animations based on player interaction
- Full scene transitions and playable build
